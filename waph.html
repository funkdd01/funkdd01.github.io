Overview

This site documents my work in Web Application Programming and Hacking (WAPH). This course teaches me how to build full-stack web applications from the ground up — front-end with HTML5, CSS, and JavaScript, and back-end with PHP and MySQL — and then attack them like a hacker would. I explore real web application vulnerabilities including cross-site scripting, SQL injection, session hijacking, and CSRF through four hands-on hackathon exercises in a controlled environment. In the class, secure programming principles and practices are woven throughout so you graduate writing code that is both functional and defensible.

Hackathons

  • Hackathon 1 - Cross-site Scripting Attacks and Defenses. This hackathon was about XSS attacks. In the first part of this hackathon, there were 7 levels of website protections and where I needed to do an XSS attack toget my own code to run on each page; in this I was successful. The second part of this lab was going back to previously written code and securing it against XSS attacks. Methods on the server involved escaping html characters and checking for an empty string. Methods on the client involved putting the responses into a div and putting that onto the page as well as checking for an empty string
